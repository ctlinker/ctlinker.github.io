# Portfolio V1 — Vision Document

> **Status**: Draft · November 2026
> **Stack**: Preact + Vite + TailwindCSS v4 + TypeScript

---

## 1. Concept

A **terminal-first portfolio** that doubles as a personal presentation website.
The UI mimics an interactive shell — visitors type (or tap) commands to explore
sections — but the chrome and aesthetic make it immediately read as a polished
site, not a toy.

The experience should feel like opening a beautiful terminal emulator that
happens to be about *you*.

---

## 2. Colour Palette — Cyan-Teal Gradient Theme

The seed (`seed.html`) already has an accent system with `purple / green / cyan / blue`.
V1 leans into a **green × blue / teal** identity — tech, calm, precise.

### Light mode
| Token       | Value       | Role                        |
|-------------|-------------|-----------------------------|
| `--bg`      | `#f0f7f4`   | Faint mint-white background |
| `--fg`      | `#0d1f1a`   | Near-black (dark teal)      |
| `--dim`     | `#5a8070`   | Dimmed text, timestamps     |
| `--acc`     | `#0e9c6e`   | Primary accent (green)      |
| `--acc2`    | `#2563eb`   | Secondary accent (blue)     |
| `--line`    | `#c8e0d8`   | Borders, dividers           |

### Dark mode (default / preferred)
| Token       | Value       | Role                             |
|-------------|-------------|----------------------------------|
| `--bg`      | `#070f0c`   | Deep near-black with green tint  |
| `--fg`      | `#c8e8dc`   | Soft mint-white text             |
| `--dim`     | `#4a7a63`   | Dimmed text                      |
| `--acc`     | `#22c97e`   | Bright terminal green            |
| `--acc2`    | `#60a5fa`   | Highlight blue (links, focus)    |
| `--line`    | `#132b20`   | Subtle separators                |

> **Gradient accent**: Key elements (prompt `>`, active chips, cursor) use a
> CSS gradient between `--acc` and `--acc2` for a distinctive green → blue glow.

## 4. Terminal Engine

### 4.1 Command register (`src/cmd/_type.ts`)
Already scaffolded — `CommandRegister` with `name`, `aliases`, `description`,
`function: (args) => string[]`. Keep this interface; each command returns
rendered lines.

### 4.2 Commands for V1

| Command      | Aliases           | Output                                      |
|--------------|-------------------|---------------------------------------------|
| `help`       | `?`               | List all commands with one-line description |
| `about`      | `whoami`          | Short bio from `infos.ts`                   |
| `skills`     | `lang`, `stack`   | Language + framework table (from `infos.ts`)|
| `projects`   | `work`            | Table: name · description · link            |
| `contact`    | `email`           | Email + GitHub row                          |
| `fastfetch`  | `ff`              | Styled system-info block (existing cmd)     |
| `theme`      | —                 | Toggle light / dark                         |
| `accent`     | —                 | Cycle green → blue → cyan → purple          |
| `clear`      | `cls`             | Clear terminal output                       |
| `lang`       | `fr`, `en`        | Switch display language                     |
| `sudo`       | —                 | Easter egg                                  |

### 4.3 Output renderer
Lines are typed character-by-character via `TypeWritter` (already in repo),
with configurable `speed` and `flavor: "plain" | "gibbrish"`.

Command output types:
- `text` — plain typed line
- `table` — two-column `<table>` (from seed pattern)
- `link` — typed anchor
- `art` — preformatted block (fastfetch / ASCII)

### 4.4 Input
- Keyboard: `>` prompt input, `↑ ↓` history navigation, `Tab` autocomplete
- Touch: chip buttons trigger commands (no keyboard needed)
- Screen-reader: `role="status" aria-live="polite"` output region

## 9. Decisions

| Question | Decision |
|----------|----------|
| **Particle colour** | Follows `--acc` (green accent) — particles inherit the active accent token |
| **i18n scope** | Full FR/EN parity — both languages maintained together |
| **Photobook** | ✅ Carry it over — keep the easter egg with the epilepsy warning |
| **ASCII logo** | ✅ Yes — stored as a plain multiline string in `infos.ts` so it can be swapped without touching any component |
| **Routing** | Single-page (seed pattern) — no deep links in V1 |
| **Deploy target** | GitHub Pages (workflow already in `.github/workflows/publish.yaml`) |

## 10. ASCII Logo — `infos.ts` integration

The ASCII art is a first-class field in `infos.ts`, not hardcoded in any component:

```ts
export default {
  me: {
    ascii: `
  ██████╗
  ██╔════╝    ctlinker@portfolio
  ██║         ─────────────────────
  ██║         OS:    ctlinker/web v1.0
  ╚██████╗    Shell: /bin/portfolio
   ╚═════╝`,
    // ↑ edit this string freely — fastfetch renders it as-is
    // …
  },
}
```

The `fastfetch` command reads `infos.me.ascii` and renders it inside a `<pre>`
block with accent-coloured key/value pairs appended on the right column.
Swapping the art = editing one string, zero component changes.
